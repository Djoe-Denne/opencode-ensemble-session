# Plans

Durable design and plan documents written by the `architect` profile, and
consumed by `implementer` spawn prompts. Each document carries a status:

- **Proposed**: awaiting explicit human approval.
- **Accepted**: approved; treat it as the contract for implementation.

A proposal becomes accepted only after explicit developer approval. Document
open questions as `OQ-<N>` with the assumption made, per AGENTS.md.
